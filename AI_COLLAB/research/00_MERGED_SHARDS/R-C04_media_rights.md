# R-C04 Media sources and legal boundaries
Gemini researched LRCLIB and Lyricsfile/LRC. LRCLIB can support user-initiated metadata lookup and synced-line retrieval; not every track has synced lyrics and multiple editions can match. API status, client identification, rate limits and terms need verification. Lyricsfile/LRC is a timing/data format, not a licence for lyric text.
Musixmatch commercial/synced access is licensed; Genius API is metadata/annotations, not scraping permission; public Apple Music APIs do not offer general lyrics access; Spotify has no public general lyrics API. Verify current providers before relying on them.
Lyrics/subtitles are usually copyrighted separately from API/format. Public API access is not display permission. No scraping lyric sites, YouTube timedtext or subtitle archives. YouTube captions download is owner-restricted. OpenSubtitles quotas and subtitle rights make it unsuitable as universal keyless source.
G1: no online third-party copyrighted lyric display in v1 without explicit approval after rights review. Default content: user text, original LingoMingle content, public domain or properly licensed CC. Never commit copyrighted lyric fixtures.
Audio: official embedded YouTube player subject to API terms; user's own legal audio files; no-audio TTS/shadowing. Do not extract audio. LRC line timestamps can drift across edits; store per-song syncOffsetMs. Word-level timing is separate from ordinary LRC.
