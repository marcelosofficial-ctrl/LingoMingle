# R-C02 Product and economics
Core loop: choose language/content -> original script + reading/romaji + translation layers -> tap token for reading/gloss/grammar/audio -> save token -> spaced review -> progress.
MVP order: hiragana visual mnemonic trainer, review/quiz engine, katakana, Hangul starter, then Song Study using user-imported/original/PD/cleared text. LingoMingle is a learning product, not a lyric catalogue.
Costs checked 2026-11-11:
- Apple Developer Program USD $99/year. Fee waiver limited to eligible nonprofits, accredited educational institutions and government entities. An individual does not qualify merely because the app is educational. Official: https://developer.apple.com/help/account/membership/program-enrollment/ and https://developer.apple.com/help/account/membership/fee-waivers/
- Google Play Console USD $25 one-time. Official: https://support.google.com/googleplay/android-developer/answer/6112435
- Expo framework/CLI free/open source; EAS optional services have free quotas to recheck: https://docs.expo.dev/faq/
- PWA can use free static hosting and Safari install; not equivalent to native store app; iOS web capabilities vary.
- Android APK direct distribution avoids Play registration, but sideloading, signing, updates and security become our responsibility.
- EU alternative iOS distribution is not a simple free loophole; Apple requires programme access, notarisation and eligibility: https://developer.apple.com/support/apps-in-the-eu/
- Free Apple account allows learning and limited device testing; distribution/TestFlight require paid membership: https://developer.apple.com/programs/
Free-first path: PWA first, Android APK for opt-in testing, iOS native store only if user approves fee. No server required for local study history. Never promise free App Store publishing.
