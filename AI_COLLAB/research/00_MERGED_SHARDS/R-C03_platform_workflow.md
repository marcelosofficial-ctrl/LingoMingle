# R-C03 Platform and phone-first workflow
Expo + React Native + TypeScript selected as candidate for iOS/Android reuse and AI-assisted phone workflow. Exact SDK/package versions NOT PINNED; verify official docs before implementation. Expo Go for JS-only prototypes; native APIs/custom modules/native UI may require development builds. EAS cloud can build iOS without Mac but does not remove Apple distribution membership fees.
Candidate packages: Expo Router, expo-sqlite, Drizzle, Reanimated, Gesture Handler, expo-speech/audio, document-picker, notifications, react-native-svg, ts-fsrs. Verify version, licence and SDK matrix before adoption.
Apple-like design: system typography, generous spacing, restrained colour, hierarchy, native transitions, haptics, accessibility, excellent empty/loading/error states. Liquid Glass only for navigation/control layer, not content backgrounds. Guard iOS glass with capability detection and Android/older-iOS fallback. Support Reduce Motion/Transparency, VoiceOver/TalkBack, Dynamic Type and contrast.
Phone workflow: GitHub source of truth; small commits; Linux CI typecheck/lint/unit tests. Prefer Expo Go/PWA-compatible JS before native builds. Laptop arrival is not prerequisite for research, architecture or domain/UI work.
